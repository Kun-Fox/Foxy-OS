# UI 规划与实现约束

屏幕 320×240（横屏 4:3，ILI9342，SPI3 @ 80MHz，FT6336 单点触摸 20ms 轮询）。

## 尺寸账

| 区域 | 高度 | 内容 |
|---|---|---|
| 状态栏 | 26 | Wi-Fi、时间、电量（点右上角进信息页） |
| 主体 | 172 | 各页内容 |
| 底部条 | 42 | 对话 / 静音 / 音量− / 音量+ / 信息 |

一帧全屏 320×240×2 = 153.6KB；刷新缓冲 320×40 行（25.6KB，内部 SRAM，DMA 直发）。
LVGL 内存池 1MB，图片缓存 512KB，PSRAM 8MB（80MHz Octal）。

## 性能基线（实测决定动画预算）

- 整屏重绘：约 45–60ms（SPI 80MHz + 40 行缓冲）→ 约 17–22fps
- 局部重绘（一个按钮/一行字）：几毫秒
- 因此：**切页用 120–160ms 的短动画 + 淡入**，不做整屏平移滑动；滑动只做"手势识别 + 立即切换"

## 页面结构

```
Home ──滑动──▶ Apps ──▶ Settings / Chat / Tools
  │                          
  └──点击消息──────────────▶ Chat
```

- **Home**：左半 160×172 像素 Foxy（低帧率循环，2–4fps），右半上 90px 时钟、下 82px 消息列表（最多 3 条，20px 行高）
- **Apps**：2×2 大图标（150×80 每格），设置 / 应用 / 对话 / 工具
- **Settings**：音量滑条、亮度、电池、IP、Flash 与 assets 占用、固件版本
- **Chat**：字幕（复用 `bottom_bar_`）+ 快捷短语按钮（"放首歌""几点""闭嘴"）
- **Tools**：计算器、触摸测试、拍照测试

## 交互约定

- 单击：按下到抬起 < 500ms 且位移 < 12px
- 长按：按住 ≥ 500ms
- 左右滑：位移 ≥ 60px 且横向占优 → 切页
- 底部条常驻，任何页都可用
- 息屏：空闲 60 秒（`wifi/sleep_dim_min=1`）关背光；触摸/唤醒词/TTS 到达时点亮

## 已实现（v0.2，2026-11-19 凌晨）

- 三页结构：`page 0 = 对话（原生界面）`、`page 1 = 首页`、`page 2 = 应用`；左右滑动切换（≥60px 且横向占优）
- 首页：左边 92×92 像素 Foxy 占位形象（纯 LVGL 图形，等素材替换）、右边时钟 + 日期 + 消息卡（3 行占位）
- 应用页：2×2 卡片（设置 / 应用 / 对话 / 工具），点"对话"回对话页，其余打印 `app tap index`
- 页面容器 320×198 @ y=0，控制条 42px 在 y=198..240，切页不影响控制条
- 自检任务：开机 4 秒后自动翻到首页、应用页、再回对话页，日志 `page=1/2/0` + `selftest done`（`FOXY_UI_SELFTEST` 可关）
- 实测整屏刷新 35–44ms（SPI 80MHz + 40 行缓冲）→ 约 23–28fps，比预估的 17–22fps 好
